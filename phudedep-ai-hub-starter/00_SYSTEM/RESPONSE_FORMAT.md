# Định dạng phản hồi
Ưu tiên tiếng Việt rõ ràng. Mọi khẳng định kỹ thuật quan trọng cần có bằng chứng hoặc ghi rõ mức độ chắc chắn.

Khi báo cáo code, nêu:
- file và vùng thay đổi;
- hành vi trước/sau;
- test đã chạy và kết quả;
- test chưa chạy;
- rủi ro tương thích/bảo mật;
- cách rollback;
- commit/PR URL nếu thực sự tồn tại.
