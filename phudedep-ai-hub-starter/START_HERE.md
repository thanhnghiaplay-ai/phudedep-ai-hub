# START HERE — Hồ sơ khởi động dự án

> Đây là trang đầu tiên mọi AI phải đọc. Không tự suy đoán những mục chưa được xác nhận.

## 1. Thông tin dự án
- Tên dự án: `phudedep`
- Mục tiêu chính: [CẦN ĐIỀN]
- Người quyết định cuối cùng: Chủ dự án
- Repository chứa hub: [CẦN ĐIỀN URL SAU KHI TẠO]
- Repository chứa mã nguồn: [CẦN ĐIỀN hoặc ghi CHƯA CÓ]
- Nhánh chuẩn: `main`

## 2. Cách phối hợp
- Chế độ trao đổi: ALL — mọi AI đọc báo cáo và phản biện báo cáo của nhau.
- Mức tự động hóa: SEMI — AI đề xuất và chuẩn bị; chủ dự án duyệt thay đổi quan trọng.
- Ưu tiên: miễn phí, thao tác được trên điện thoại.
- Không AI nào được tự merge vào `main`.

## 3. Tình trạng đã xác minh
- Trạng thái hub: CHƯA TRIỂN KHAI LÊN GITHUB
- Trạng thái code dự án: CHƯA XÁC MINH
- AI đã kết nối: CHƯA CÓ
- Task đang thực hiện: chưa có

## 4. Việc cần làm đầu tiên
1. Tạo GitHub repository và tải bộ khung này lên.
2. Bật Discussions và tạo các danh mục theo `02_COLLABORATION/GITHUB_SETUP.md`.
3. Điền hồ sơ dự án từ tài liệu/code thật; không bịa chức năng.
4. Tạo Task đầu tiên để kiểm kê cấu trúc và trạng thái code hiện có.
5. Sau mỗi chặng, cập nhật `01_MEMORY/CURRENT_STATE.md` và `05_RECOVERY/CHECKPOINTS.md`.

## 5. Quy tắc dữ liệu
Chỉ ghi dữ liệu đã xác minh. Gắn nhãn `UNKNOWN` cho điều chưa biết, `ASSUMPTION` cho giả định và `VERIFIED` cho điều đã kiểm chứng.
